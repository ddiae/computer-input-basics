# Mouse Control Basic (마우스 기초 마스터)

초등학교 1~2학년(6~8세) 어린이들을 위한 마우스 및 키보드 조작 연습 애플리케이션입니다.

## 🎯 프로젝트 목표

- 마우스 왼쪽 클릭, 더블클릭, 드래그앤드롭 익히기
- 마우스를 이용한 선 긋기 및 점 잇기 연습
- 키보드 방향키 조작 능력 습득
- 소근육 발달 및 디지털 리터러시 기초 함양

## 🚀 주요 기능 (총 10단계)

### 기본 단계 (STEP 1~5)

- **STEP 1 — 클릭 (Click):** 풍선 터뜨리기 🎈
- **STEP 2 — 더블클릭 (Double Click):** 꽃 피우기 🌸
- **STEP 3 — 드래그앤드롭 (Drag & Drop):** 동물 집 찾아주기 🏠
- **STEP 4 — 선 긋기 (Mouse Drawing):** 점선 따라 그리기 ✏️
- **STEP 5 — 선 잇기 (Connect the Dots):** 숫자 순서대로 점 잇기 🔢

### 심화 단계 (STEP 6~9) - _기본 3단계 이상 완료 시 해금_

- **STEP 6 — 정밀 클릭 (Precision Click):** 작아지는 과녁 맞추기 🎯
- **STEP 7 — 빠른 클릭 (Speed Click):** 두더지 잡기 ⏰
- **STEP 8 — 정밀 드래그 (Precision Drag):** 미로 탈출 🎱
- **STEP 9 — 복합 미션 (Multi-Action Challenge):** 요리하기 🍳

### 키보드 단계 (STEP 10) - _기본 5단계 완료 시 해금_

- **STEP 10 — 무한의 계단 (Infinite Staircase):** 방향키 조작 플랫폼 게임 ⭐

## 🛠 기술 스택

- **Framework:** React (Functional Components)
- **Language:** TypeScript
- **Styling:** Vanilla CSS
- **Build Tool:** Vite
