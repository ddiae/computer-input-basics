# Mouse Control Basic (마우스 & 키보드 기초 마스터)

초등학교 1~2학년(6~8세) 어린이들을 위한 마우스 및 키보드 조작 연습 애플리케이션입니다.

## 🎯 프로젝트 목표

- 마우스 클릭, 더블클릭, 드래그앤드롭 익히기
- 마우스를 이용한 선 긋기 및 점 잇기 연습
- 키보드 숫자 키, 방향키, 특수 키 조작 능력 습득
- 소근육 발달 및 디지털 리터러시 기초 함양

## 🖱️ 마우스 연습 (총 5단계)

- **STEP 1 — 클릭 (Click):** 풍선 터뜨리기 🎈
- **STEP 2 — 더블클릭 (Double Click):** 꽃씨 피우기 🌸
- **STEP 3 — 드래그앤드롭 (Drag & Drop):** 동물 집 찾아주기 🏠
- **STEP 4 — 선 긋기 (Mouse Drawing):** 점선 따라 그리기 ✏️
- **STEP 5 — 챌린지 (Challenge):** 별 잇기 · 클릭 구별 · 당근 드래그 🏆

## ⌨️ 키보드 연습 (총 5단계)

- **STEP 1 — 숫자 키:** 화면에 나온 숫자를 키보드에서 찾아 눌러요 🔢
- **STEP 2 — 방향키:** 방향키로 고양이를 움직여 별을 잡아요 🕹️
- **STEP 3 — 단어 입력:** 한영키로 언어를 바꾸며 단어·문장을 따라 써요 ✍️
- **STEP 4 — 키 위치:** 화면에 나온 키를 빠르게 찾아 눌러요 ⌨️
- **STEP 5 — 키 이름:** Ctrl·Shift·Enter·Space 읽는 방법을 연결해요 🔤

## 🛠 기술 스택

- **Framework:** React (Functional Components)
- **Language:** TypeScript
- **Styling:** Vanilla CSS (inline styles)
- **Build Tool:** Vite
- **Routing:** React Router v6
